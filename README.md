# Lumen Hollow

Маленький огонёк пробуждает спящий квартал. Освети предмет целиком, отправь к нему свет и рассей дымку. Деревья, дома и окна остаются тёплыми после твоего ухода. Цель — зажечь часовую башню.

**[Играть в браузере](https://andreibohun-hash.github.io/lumen-hollow/)**

## Управление

- Телефон: зажми палец и веди огонёк; короткий тап задаёт точку движения.
- Компьютер: WASD или стрелки, Escape — пауза, R — заново.
- Звук отключается кнопкой в правом верхнем углу.

## HTML

`index.html` — самодостаточная версия игры: код, Three.js 0.185.1 и шрифты Nunito включены внутрь. Ничего устанавливать и собирать не нужно. Скачай файл и открой в браузере или играй по ссылке выше.

Один уровень, портретная компоновка, WebGL-свет и силуэты, синтез звука WebAudio. В настройках среза доступны скорость времени и автобот. Исходный код не минифицирован.

Версия v8: золотистая надпись «Свет возвращён» поднимается над очищенным предметом и плавно растворяется.
